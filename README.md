# PulseVoice para Windows

Salas de conversa com voz, mensagens e webcam, para até 8 pessoas. Versão experimental para Windows 10/11 de 64 bits.

## Download

[Baixar PulseVoice.exe](https://github.com/OppressorLiber/pulsevoice-releases/releases/latest/download/PulseVoice.exe) · [Todas as versões](https://github.com/OppressorLiber/pulsevoice-releases/releases)

Abra o executável em uma pasta com permissão de escrita. Não precisa instalar Python.

## Atualizações

A partir da versão 0.5, o aplicativo verifica novas versões ao abrir. Clique em **Atualizações**, baixe a versão disponível e, fora de uma sala, escolha **Instalar e reiniciar**. O download é verificado por SHA-256 informado pelo GitHub, e o executável anterior fica como backup.

As versões 0.4 e anteriores precisam deste primeiro download manual. Depois, as próximas atualizações são feitas pelo aplicativo.

## Conversar

Escolha seu nome, crie uma sala e copie o convite. Dentro da sala, **Dispositivos** permite escolher microfone, fones e webcam. Para usar o celular com LumaCam, mantenha a webcam virtual ativa e escolha **LumaCam Camera**. O criador da sala precisa permanecer conectado.

A meta de 10 ms ainda não é uma latência completa medida ou garantida.

Este repositório contém apenas versões de distribuição e documentação. O código-fonte permanece local. Não envie credenciais, convites de salas ou conversas nos relatos públicos de problemas.
